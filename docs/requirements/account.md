# アカウント機能 要件定義書

## 1. 背景と目的

本アプリケーションには現在ユーザーという概念が存在せず、すべてのページが匿名かつ全員に共有された状態にある。
ページの所有・共有を実現するには、その土台となる「誰であるか」を識別する仕組みが必要になる。

本機能では、その第一歩としてログイン / ログアウトを実現し、アプリケーションがリクエストの主体を識別できる状態をつくる。
認可（誰がどのページを操作できるか）は本書の対象外とし、識別基盤を先に確立することを目的とする。

## 2. スコープ

### 2.1 対象

- ログイン
- ログアウト
- ログイン中ユーザーの情報取得
- アカウント情報をアプリケーション DB に保持すること
